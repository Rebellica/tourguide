# 上海导游资格考试备考网站

纯前端静态网页，用于在手机上刷题、背导游词、模拟考试。数据全部从本地复习资料整理生成，无需后端、无需构建工具，可直接通过 GitHub Pages 访问。

## 目录结构

- `docs/` — 网站源码（GitHub Pages 从此目录发布）
  - `index.html` / `css/style.css` / `js/app.js` — 页面与逻辑
  - `data/questions.json` — 历年真题 + 模拟题题库（判断/单选/多选，共1400+题）
  - `data/guide.json` — 上海各游览区导游词（外滩、人民广场、豫园、东方明珠、龙华、徐家汇源）
  - `data/interview_qa.json` — 面试问答题库（服务规范/应变技能/综合知识，共780+题）
- `格式化题库/` — 原始整理的历年真题 Markdown（题库数据来源之一）
- `extract_pdf.py` — 早期用于从PDF批量提取真题文本的脚本

## 功能

- **分科刷题**：按科目（一二/三四）、年份、题型筛选练习，即时反馈对错和解析
- **模拟考试**：计时组卷，交卷后自动判分并可查看逐题解析
- **导游词背诵**：分景区浏览，支持"背诵模式"随机挖空自测
- **面试问答**：翻卡片式练习面试常见问答
- **错题本**：自动收集练习/考试中的错题，支持专项复习
- **学习统计**：记录每日做题量、正确率、模拟考试历史

所有学习记录保存在浏览器 localStorage 中，不上传任何服务器。

## 部署

GitHub Pages 设置为从 `main` 分支的 `/docs` 目录发布。

## 数据说明

题库数据整理自历年真题（2016-2025）及模拟题资料，部分年份（如2022年）原始资料为扫描图片，经OCR识别后可能存在个别文字识别误差；系统已对选项与答案不匹配的题目做了自动过滤，但仍建议以官方教材和最新考纲为准。
